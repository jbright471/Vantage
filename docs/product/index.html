Why operators use it

Truth over appearance.

Observe first

Vantage watches your existing Ollama, agents, schedulers, and routing stack instead of replacing them.

Act deliberately

Routing edits, node refreshes, quarantine, and eval runs are explicit and recorded as durable runs.

Ship locally

Docker Compose, SQLite, signed audit bundles, shared-token or HMAC agents, integration endpoints, and release bundles keep deployment understandable.

Try it

Run the public-safe demo.

Copy-Item .env.example .env
(Get-Content .env) -replace '^VANTAGE_DEMO_MODE=.*', 'VANTAGE_DEMO_MODE=1' | Set-Content .env
docker compose up --build -d
