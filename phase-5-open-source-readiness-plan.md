# Phase 5 Open Source Readiness Plan

## Goal
Make Vantage easy to try, evaluate, and contribute to as an open-source local AI command center without exposing private homelab details.

## Tasks
- [x] Add demo-mode seeded data behind `VANTAGE_DEMO_MODE=1` -> Verify full-state API has nodes, runs, models, warnings, evals.
- [x] Add first-run onboarding checklist in the UI -> Verify checklist renders with setup steps and can be dismissed locally.
- [x] Add open-source repository docs: license, changelog, onboarding, release checklist, screenshot guidance -> Verify docs scan clean.
- [x] Update README, Operator Guide, Roadmap, Security, Release docs for open-source posture -> Verify app docs endpoint serves updated guide.
- [x] Run backend tests, frontend tests, build, release-bundle scan, and diff checks.

## Done When
- [x] A new operator can clone the repo, run demo mode, read onboarding, and understand the production path without seeing private config.
